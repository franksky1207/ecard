此文件完整記錄網頁、Scriptable `school`、iPhone「刷卡自動檢查」捷徑、學校刷卡系統的分工與資料流程；包含功能、已驗證與未驗證事項、建立歷程、待改善項目、資料安全規則及未來新對話交接指令。

## 目前狀態

- 網頁：每週時間表、特殊日期、提醒開關、下班後延遲、localStorage 儲存、剪貼簿複製、JSON 備份／還原；已部署 GitHub Pages。
- iPhone Scriptable：使用者已安裝 `school`，手動登入查詢及設定匯入曾測試成功；程式與帳密不在此公開儲存庫。
- iPhone 捷徑：使用者已建立「刷卡自動檢查」，鎖定手機後定時觸發前置測試通知成功。
- **尚待驗證**：鎖定手機時 `school` 完整查詢並發出正式刷卡通知；特殊日期的任意時間觸發、網頁到手機自動同步亦尚未完成。
- 網頁設定只存在當前瀏覽器；按「複製到 iPhone」後仍需在 Scriptable 手動匯入。捷徑固定觸發時間不會因網頁設定改變而自動調整。

## 安全提醒

請勿把學校帳密、Cookie、Token、私人刷卡紀錄寫入公開 GitHub 或網頁備份。改動前請閱讀完整說明，並以最新 `main` 程式碼與手機實機狀態核對。
