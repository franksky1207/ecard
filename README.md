## 安全與協作

本儲存庫是公開的：不得上傳學校帳密、Cookie、Token、個人刷卡紀錄或機密設定，也不要動用戶其他班級系統的 Supabase。手機 Scriptable、捷徑不在 GitHub；所有修改都要區分網頁程式已完成、Scriptable 原始碼已交付、及 iPhone 真機已驗收三種層級。
