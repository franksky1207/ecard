# ecard｜學校智慧刷卡提醒系統

第一階段：響應式網頁設定中心（尚未部署）。

## 現有功能
- 星期日～六獨立設定上班、刷卡有效門檻、上班提醒、預計下班及提前提醒分鐘數
- 提醒總開關、上下班提醒開關、再次確認
- 指定日期休假、補班、加班及臨時時間覆寫
- 瀏覽器 localStorage 本機儲存，JSON 匯出／匯入
- iPhone Safari 與桌面響應式介面

## 重要限制
- **尚未啟用雲端同步、學校網站登入、自動查詢或 iPhone 通知。**
- localStorage 只在同一瀏覽器及來源有效；清除瀏覽資料可能遺失設定。請定期匯出 JSON 備份。
- 不要把學校帳號密碼或 Cookie 寫入 GitHub、網頁原始碼或 JSON 備份。
- 尚未發布 GitHub Pages。若將來公開發布，網頁資產可被任何人存取；正式個人設定需獨立登入驗證及後端權限控管。

## 本機預覽
下載或 clone 本儲存庫，在專案目錄執行：
```bash
python3 -m http.server 8000
```
瀏覽 http://localhost:8000/ 。

## 既有設定規則
- 星期一／四／五預計下班 20:40，星期二／三 17:30。
- 上班提醒 06:30、07:00，提前下班提醒 5 分鐘。
- 上班有效刷卡門檻 07:30，下班 16:45。
- 星期六、日預設不上班。
- 上班和下班有效刷卡判定不能只看欄位是否非空；例如 06:21、06:21 不代表已完成下班刷卡。
