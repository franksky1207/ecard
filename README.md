### 目前已實測成功

- iPhone iOS **27.0.1**、Scriptable 最新使用版：`school_每週特殊日期_動態排程_完整正式測試版_20261020.txt`（**程式位於 iPhone／先前 ChatGPT 交付附件，未存放於公開 GitHub**）。
- **特殊日期與一般星期的動態首次檢查都已成功**：改網頁設定、儲存、複製匯入 Scriptable、鎖定手機，不需手動按捷徑即可啟動實際刷卡查詢及必要提醒。
- **持續再次確認成功**：依網頁自訂間隔重新查詢，未刷卡時繼續提醒。10/20 曾用 1 分鐘間隔實測；最長提醒時間介面支援 30～360 分鐘。

- 設定網頁保留每週、特殊日期、有效刷卡判斷、下班後延遲、剪貼簿 JSON 匯入、備份；**網頁仍非自動即時同步手機**。

### 目前手機保留／待整理項目

- **正式 Scriptable**：`school` 必須保留、`school(預備)` 備份建議保留。舊測試腳本 `ecard-test-start`、`ecard-test-finish` 已無正式用途，用戶已著手清理；其實際手機刪除狀態無法透過 GitHub 確認。
- **三支捷徑目前全部保留**：「刷卡自動檢查」舊四個固定時間（06:30、07:00、17:32、20:42）；「刷卡再次確認」通知 `🔄 刷卡再次確認`、參數 `ecard_recheck`；「特殊日期首次檢查」通知 `📅 刷卡首次檢查`、參數 `ecard_first`。**現在不要刪除舊四個固定時間捷徑**。
- **尚待驗證與改善**：刷卡成功停止、達最長提醒時間停止、錯誤重試與去重、14 天滾動排程跨長假的續排，及確認安全後簡化舊固定時間捷徑；測試診斷通知也可於最後移除。
- **測試結束的必要善後**：把臨時星期二／特殊日期的下班時間、1 分鐘再次確認間隔恢復正式值，儲存、複製、重新匯入 Scriptable。
